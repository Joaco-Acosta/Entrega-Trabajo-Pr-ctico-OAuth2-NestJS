# Trabajo Práctico: Backend de Registro y Autenticación con NestJS y Google OAuth2

Este repositorio contiene el código fuente de un microservicio backend desarrollado con **NestJS**. Su objetivo principal es resolver el flujo de autenticación centralizado utilizando el proveedor **Google OAuth2** y gestionando las sesiones a través de la emisión de un JSON Web Token (JWT).

_Nota: Esta versión del proyecto se centra en la resolución del flujo OAuth2, validación de endpoints y emisión del token JWT, omitiendo temporalmente la persistencia en base de datos._

## 📋 Requisitos Previos

Antes de comenzar, asegúrate de tener instalado:

- **Node.js** (v18 o superior) y npm.
- Una cuenta en **Google Cloud Console** para generar las credenciales OAuth2.
